# Tourism Management System

## 📌 Project Overview

Tourism Management System is a web-based application developed to simplify the process of managing tour packages, user registrations, bookings, enquiries, and admin operations.

## 🚀 Features

- User Registration and Login
- User Profile Management
- Browse Tour Packages
- Package Details
- Tour Booking
- Check Package Availability
- Booking History
- Enquiry Management
- Issue/Ticket Management
- Admin Dashboard
- Admin Login
- Manage Tour Packages
- Manage Users
- Manage Bookings
- Manage Enquiries

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
- XAMPP

## 🗄️ Database

The project uses **MySQL** as the database.

Database file:

`tms.sql`

## ▶️ How to Run the Project

1. Install XAMPP.
2. Start **Apache** and **MySQL** from XAMPP.
3. Copy the project folder into:

`C:\xampp\htdocs\`

4. Make sure the folder name is:

`tms`

5. Open phpMyAdmin.
6. Create a database named:

`tms`

7. Import `tms.sql` into the database.
8. Open the project in your browser:

`http://localhost/tms/`
